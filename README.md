# Structured Programming Practice

This repository contains a collection of C programming practice exercises. Each directory contains a specific concept.

## Repository Structure

The project is organized into subfolders for each concept, with individual `exercise.c` files.

## Programming Categories Summary

### 1. Basic Output
* **Folder:** `01_basic_output/`
* **Concepts:** `printf()`
* **Description:** Displays clear, formatted output to the console window.

### 2. Input - Process - Output
* **Folder:** `02_input_process_output/`
* **Concepts:** Variables, `scanf()`, arithmetic operations
* **Description:** Reads input from the user, performs a mathematical calculation, and displays the final result.

### 3. Decision
* **Folder:** `03_decisions/`
* **Concepts:** `if`, `if...else`, `else if`
* **Description:** Evaluates conditions based on user input and branches execution to display the appropriate result.

### 4. Basic Loop
* **Folder:** `04_basic_loops/`
* **Concepts:** `for` loop or `while` loop
* **Description:** Repeats a clear task a specific number of times using a correctly controlled loop structure.

### 5. Loop with Calculation
* **Folder:** `05_loops_with_calculation/`
* **Concepts:** Loop control structures paired with arithmetic operations
* **Description:** Uses a loop variable or repeated values dynamically inside an accumulating calculation.

### 6. Loop with User Input
* **Folder:** `06_loops_with_user_input/`
* **Concepts:** Loop control structures paired with `scanf()`
* **Description:** Collects several individual input values from the user progressively during repetition.

### 7. Loop with Decision
* **Folder:** `07_loops_with_decisions/`
* **Concepts:** Loops paired with nested `if/else` structures, tracking counters
* **Description:** Makes specific logic decisions during each iteration of the loop while maintaining counter variables.

### 8. Interactive Console Program
* **Folder:** `08_interactive_console_program/`
* **Concepts:** Menu interfaces, sentinel values, loop structures, and decisions
* **Description:** A continuous program that keeps interacting with the user via a menu system until a specific exit condition is selected.
